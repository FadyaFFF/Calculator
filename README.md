# 🧮 Калькулятор на Tailwind CSS

Современный веб-калькулятор со стеклянным дизайном, полной поддержкой клавиатуры и адаптивной вёрсткой. Создан с использованием **Tailwind CSS** и чистого JavaScript.

## ✨ Возможности

- ✅ Базовые арифметические операции: сложение, вычитание, умножение, деление
- ✅ Дополнительные функции: процент (%), смена знака (±), очистка (AC)
- ✅ Отображение текущего выражения и результата
- ✅ Умная обработка длинных чисел (автоматический переход к экспоненциальной записи)
- ✅ Полная поддержка клавиатуры:
  - Цифры `0-9`, точка (`.`)
  - Операторы: `+`, `-`, `*`, `/`
  - `Enter` или `=` для вычисления
  - `Esc` или `C` для очистки
  - `%` для процента
- ✅ Адаптивный дизайн – корректно отображается на мобильных устройствах
- ✅ Приятная анимация нажатия кнопок и подсветка результата

## 🚀 Запуск

Просто откройте файл `index.html` в любом современном браузере – никаких зависимостей, сервер не требуется.
